# MOSAIC has moved

MOSAIC moved from `AoW2-MFL-CGIAR-Science-Program` to **[MOSAIC-mfl](https://github.com/MOSAIC-mfl)** on 2026-09-28. This organization only holds the old name, so that nobody else can claim it and so that old links keep working.

This repository publishes one page at `https://aow2-mfl-cgiar-science-program.github.io/`. It serves every old address (`index.html` and `404.html` are the same file) and forwards it, with the rest of the path, to its new home:

| Old path | New address |
|---|---|
| `/mfl-living-landscapes-frontend/…` | `https://mosaic-mfl.github.io/website/…` |
| `/MOSAIC_catalog/…` | `https://mosaic-mfl.github.io/catalog/…` |
| `/MOSAIC_vision_foundation/…` | `https://mosaic-mfl.github.io/vision-foundations/…` |
| anything else | `https://mosaic-mfl.github.io/website/` |

**Do not create repositories named `MOSAIC_catalog`, `mfl-living-landscapes-frontend` or `MOSAIC_vision_foundation` in this organization.** GitHub still forwards the old `github.com/AoW2-MFL-CGIAR-Science-Program/<repo>` links to `MOSAIC-mfl`, and a repository with one of those names would stop that.
